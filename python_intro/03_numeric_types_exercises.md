# Numeric types and conversions — exercises

> Topics: `int`, `float`, `type()`, `int()`, `float()`, `round()`.

### 1. Sampling rate.

A recorder collects `36` samples in `8` seconds. Store the sample count and time as integers. Calculate samples per second and check the result type.

### 2. Pixel indices.

Image coordinates are column `125.9` and row `88.4`. Pixel indices must be integers. Convert both values with `int()`. Calculate the discarded fractional parts.

### 3. Height correction.

An integer height is `275` m. Add a correction of `0.75` m. Check the types of the original height, correction, and result.

### 4. Height report.

A height measurement is `129.7` m. A report needs whole metres. Compare `int()` and `round()`.

### 5. Decimal precision.

Add `0.1` and `0.2`. Inspect the result in the console. Store a result rounded to one decimal place.

### 6. Float conversion.

A sample count is the integer `7`. Convert it to a floating-point number with `float()`. Check both types.

### 7. Negative value.

A height change is `-3.8` m. Compare its values after `int()` and `round()`.

### 8. Temperature precision.

A temperature is `18.756` °C. Round it to one and two decimal places. Keep the original value.

### 9. Division result types.

There are `17` rows, with `4` rows per group. Calculate the number of groups and the number of full groups. Check the type of each result.

### 10. Full intervals.

A line is `13` m long. Sampling intervals are `2.5` m. Calculate the number of intervals as a decimal, then use `int()` to find how many full intervals fit.
