# Arithmetic operators — exercises

> Topics: `+`, `-`, `*`, `/`, `//`, `%`, `**`, parentheses. Do not use variables.

### 1. Recording time.

A recording lasts `367` minutes. How many full hours and how many minutes remain?

### 2. Pixel count.

An image has `1024` columns and `768` rows. Calculate the number of pixels.

### 3. Raster size.

A single-band image has `1200 × 800` pixels. Each pixel uses `2` bytes. Calculate its size in bytes and MiB (`1 MiB = 1024²` bytes).

### 4. Photo storage.

An archive contains `487` photos. One disc holds `24` photos. How many full discs can be filled? How many photos remain?

### 5. Ground area.

A square raster has `4096 × 4096` pixels. Pixel size is `0.5` m. Calculate the ground area in hectares (`1 ha = 10,000 m²`).

### 6. Sensor values.

A sensor stores unsigned `12`-bit values. How many distinct values are possible? What is the maximum value?

### 7. Mean rainfall.

Five rainfall measurements are `12`, `19`, `11`, `17`, and `21` mm. Calculate the mean.

### 8. Percentage increase.

The number of detected objects increased from `80` to `92`. Calculate the percentage increase relative to the original value.

### 9. Map distance.

A distance of `7.6` cm is measured on a map at scale `1:25,000`. Calculate the ground distance in kilometres.

### 10. End time.

Recording starts at `22:45` and lasts `155` minutes. Calculate the end hour and minute, including the change to the next day.
