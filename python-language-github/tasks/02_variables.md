# Variables – tasks

Use only the material covered up to and including this chapter.

## Task 1. Valid names

Rewrite these proposed names as valid, descriptive course-style variable names: `2band`, `pixel-size`, `class`, `CloudCover`. Assign the values 4, 10, 2 and 15, respectively. Display each value by evaluating its name.

## Task 2. Survey area

A rectangular survey is 450 m long and 320 m wide. Store the dimensions in variables. Calculate the area in m² and store it in a third variable. Reassign the width to 400 m and calculate the updated area using the same expression.

## Task 3. Data volume

An image has 2,048 rows, 1,024 columns, 4 bands and 2 bytes per sample. Store these values in variables. Calculate the size in bytes, then convert the same size variable to MiB using augmented assignment and a named constant (1 MiB = 1,024² bytes).

## Task 4. Storage budget

A processing workspace has 500 GiB free. Store the free space in a variable. Use augmented assignment to subtract 180 GiB of input data, subtract 95 GiB of intermediate results and add back 60 GiB after cleanup. Display the free space after each operation.

## Task 5. Electric energy

A device consumes 250 W for 6 h. Store power and duration in variables. Define a constant for the number of watts in a kilowatt. Calculate energy in kWh. Reassign the duration to 9 h and recalculate without changing the constant.
