# Basic data types – tasks

Use only the material covered up to and including this chapter.

## Task 1. Survey metadata

Store the following values using suitable Python types: 240 photographs, a pixel size of 0.025 m, an orthophoto availability flag set to true, a project ID `UAV-07`, and an elevation result that is not yet available. Inspect each type.

## Task 2. Numeric literals

Represent 25 million pixels using an integer literal with digit separators and using scientific notation. Represent 0.000008 m in scientific notation. Display the values and inspect their types.

## Task 3. Division result types

A 120 m profile is divided into 6 equal sections. Calculate the section length with `/` and `//`, and inspect both result types. Repeat for a profile of 125 m.

## Task 4. Missing measurement

A height measurement is initially unavailable. Assign `None` to a variable and inspect its type. Later, assign 312 to the same variable, then replace it with the refined value 312.75. Inspect the type after each assignment.

## Task 5. Numeric identifiers

A survey point has the identifier `0042` and a measured height of 42 m. Store the identifier as text and the height as an integer. Also store the height as a floating-point literal in a separate variable. Display all three values and inspect their types.
